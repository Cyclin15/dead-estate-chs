**安装:把 `死亡庄园汉化补丁v3g.zip` 解压到游戏根目录,覆盖 `data.win`,即完成安装。**

游戏根目录:
```
D:\Steam\steamapps\common\Dead Estate\
```
(其他位置安装的 Steam,在库里右键游戏 → 管理 → 浏览本地文件即可打开)

- 原版备份 MD5:`7A4FF3EAD25B8AD3D742201A1323AD04`(76,636,556 字节,在 `backup_original\`)

> 本机游戏目录 `D:\Steam\steamapps\common\Dead Estate\data.win` 目前已经装好这一版,直接开游戏即可。

## 怎么还原

- 用本目录 `backup_original\data.win` 覆盖游戏目录的 `data.win`;或者
- Steam 里右键游戏 → 属性 → 已安装文件 → 验证游戏文件完整性(会自动还原为英文版)

## 汉化内容

- **4,910 条译文**,覆盖对话、道具/武器/诅咒描述、UI、勋章、挑战、安雅模式全篇文本
- **34 个游戏字体全部重建**,中文采用「缝合像素字体」(Fusion Pixel Font),像素风格与游戏美术一致,放大后笔画锐利不发糊;拉丁字形与原始度量保持不变,英文部分排版不受影响
- **「安雅的任务」模式的两个特殊字体**(手写体、打字机体)新增中文版本,安雅剧情文本以中文呈现
- 标题画面游戏名显示为**「死亡庄园」**;画面下方 NEWGROUNDS 为品牌标识,按惯例保留英文
- 按原版英文保留的几处:选人界面的「PLAY!」按钮与「COSTUME」标签、难度名称(TOO YOUNG TO DIE / NORMAL / PAINFUL / NIGHTMARE / X MUST DIE,悬停时的难度**描述**为中文)、街机挑战倒计时词(HURRY / NICE / WIN / BADASS)
- 未翻译项:图片内嵌文字(按需求范围排除)、GifHx / GMLive / devTool 等约 180 条非玩家可见的库调试文本,以及 4 条与游戏内部函数名/变量名/资源名同名的文本(`floor`、`level`、`explode`、`Book`,翻译会导致启动崩溃或运行异常)

## 存档兼容(请读一下)

- **老存档完全兼容**:所有存档读写的键名都保持英文,进度、统计、勋章、解锁角色、诅咒奖励、安雅模式存档均不受影响(其中 35 个存档键字符串已特意回退为英文以保证这一点)
- **唯一的小影响**:挑战手册里各挑战的「已开始 / 已完成」标记会重置一次。原因是挑战的显示名称已翻译,存档里的标记键随之改变。**已解锁的挑战会根据你已有的勋章自动恢复,不需要重打**;只有"进行中/已完成"的勾选状态会清零一次,之后正常记录
